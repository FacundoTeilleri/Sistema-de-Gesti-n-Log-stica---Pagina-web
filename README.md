# Sistema de Gestión Logística

Página web de una empresa de logística que hice como trabajo del curso de Programador Web.

Tiene tres páginas: inicio, nuestra flota y contacto. En la parte de envíos hay una calculadora que estima el costo del envío y muestra el resultado con SweetAlert2.

## Tecnologías

- HTML
- CSS
- JavaScript
- SweetAlert2

## Cómo verlo

Descargá el repositorio y abrí el archivo `index.html` en el navegador.
